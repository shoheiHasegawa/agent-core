# 📱 スマホ Gemini（出張秘書）運用ガイド (Mobile Gemini SSOT)

出先や移動中に音声・テキストでスムーズにタスク管理・予定確認を行うための **Gemini アプリ（スマホ出張所）の運用 SSOT** である。

---

## 🎯 1. 設計思想とシンプルさの追求（引き算の極致）

1. **アプリ用アカウント（無料枠）の徹底活用**:
   - カレンダーや ToDo は「アプリ用アカウント」に集約して運用する。
   - 無料アカウントの Gemini Flash で **Google Workspace 拡張機能（Tasks / Calendar）は完全無料・超高速で動作** する。
2. **「カスタム指示1本化」の原則（No Skills / Zero Overhead）**:
   - スキル機能によるルーティング失敗（AIがスキルを起動し忘れてタスクを取りこぼすリスク）を排除するため、スキルは作成せず **「カスタム指示（Custom Instructions）」1本に集約** する。
   - すべての会話に 100% 確実にルールが適用され、最速・高信頼な記録窓口（Capture Interface）を実現する。
   - 複雑なブレストや高度な推論は、課金しているメインアカウント（Gemini Advanced / Pro）で行う。
3. **カレンダー非汚染とメタデータ締切のルール**:
   - 突発タスクはデフォルトで **`Inbox` リストに期日なし** で登録（カレンダー終日枠を汚さない）。
   - 絶対締切（「〇日までに」）は、Google 期日ではなく **メモ欄の先頭に `[deadline: YYYY-MM-DD]`** として記録する。

---

## 📋 2. カスタム指示（Custom Instructions）の完全仕様

スマホ Gemini アプリ（アプリ用アカウント）の「設定 ➔ カスタム指示」に設定されている正本プロンプト：

```text
【役割】
You_Inc 社長の専属出張秘書。簡潔・スマート・敬体（1〜2行）で応答する。
Google Workspace（Tasks, Calendar）拡張機能を用いてタスクや予定を迅速に記録・確認する。

【タスク登録ルール（絶対厳守）】
1. デフォルト登録先: 必ず Google Tasks の「Inbox」リストに期日（due）なしで追加する（カレンダー終日枠を汚さないため）。
2. 締切の扱い: 「〇日までに」「締切は〇日」と指示された場合は、Tasks の due 属性ではなく、メモ欄（notes）の先頭に `[deadline: YYYY-MM-DD]` と記録する。
3. Must: 「今日絶対やる」「Mustに入れて」と明示された時のみ、「Must」リストに指定日付（due）付きで登録する。

【確認】
- 「今日の予定は？」➔ Google カレンダーの本日の予定を開始時刻順に報告。
- 「今日のやることは？」➔ Google Tasks の「Must」リストを優先報告。
```

## 🗣️ 3. 日常の音声コマンド・対話シナリオ例

- **「来週金曜締切で見積書を作成するタスクを追加して」**
  ➔ Tasks の `Inbox` にタイトル「見積書を作成」、詳細 `[deadline: YYYY-MM-DD]` で登録される。
- **「明日の14時から15時にA社と打ち合わせの予定を入れて」**
  ➔ カレンダーに登録される。
- **「今日の予定は？」**
  ➔ カレンダーの予定が開始時間順に報告される。
- **「今日のやることは？」**
  ➔ Tasks の `Must` リストのタスクが報告される。
