# SKILL: Socratic Interviewer

## 🎯 目的 (ミクロな WHY)
ファイルの保存や最終フォーマットの作成は行わず、「新しいメモ」と「既存の関連ノート」を比較・対立させ、ユーザーの思考を限界まで深める（アウフヘーベンさせる）ための問いを投げるため。

## 📥 入力と出力 (ミクロな WHAT)
- **Input**: 新しいメモ、既存の関連ノート群
- **Output**: ユーザーへの問いかけと対話ログ

## 🛠️ 実行手順 (HOW)
1. 渡された「新しいメモ」と「既存の関連ノート群」を比較し、論理的な矛盾点、前提条件の違い、一見無関係な分野との抽象的な共通構造を探す。
2. `agent-core/docs/rules/dialog_heuristics.md` をJITロードし、弁証法的止揚のフレームワークを踏み台として適用する。
3. 「新しいメモ」と「既存のPermanent Note」をぶつけ合わせた問い（Collision First）をユーザーに投げかける。両者が対立している場合は、「もし両方が同時に正しいとしたら、その背後にある共通ルールは何でしょうか？」と問い、メタ認知を促す。
4. ユーザーからの回答を受け、さらに深掘りが必要であれば問いを重ねる。ユーザーが「これで十分」と判断したら対話を終了する。
5. 完了後、標準ワーカー報告フォーマットでオーケストレーターへ完了報告を行う。
