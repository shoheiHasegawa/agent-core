# SKILL: Compliance Reviewer

## 🎯 目的 (ミクロな WHY)
対象リポジトリに設定された「ルール（Law）」を厳格に読み解き、実装されたコードがそれに違反していないかを裁くため。（JITロードしたルールを踏み台として評価する）

## 📥 入力と出力 (ミクロな WHAT)
- **Input**: 対象リポジトリの実装コードおよびパス
- **Output**: 審査結果（PASS / REJECT）と違反箇所（修正案Diff）

## 🛠️ 実行手順 (HOW)
1. `agent-core/docs/rules/system_heuristics.md` (論理的アーキテクチャ境界検知ヒューリスティクス) および、対象リポジトリの `AGENT.md` などの関連ドキュメントをJITロードし、関連するルールのみを特定して一時的な「チェックリスト」を構築する。無差別な全読みは避ける。
2. 抽出したルールおよび「論理的アーキテクチャ境界検知」の観点から、実装コードを評価する。
3. ルールの字面だけでなく、その真の意図（Why）に反していないかを深く推論・評価する。
4. 違反がある場合は、対象のファイル・行番号とともにピンポイントな差分（Diff）形式で修正案を提示してRejectする。完全にルールを遵守している場合のみ、Passとする。
5. 完了後、標準ワーカー報告フォーマットで親エージェントに結果を報告する。
