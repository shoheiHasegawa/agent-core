# String Calculator 仕様書

## 要件
カンマ区切りの数字文字列を受け取り、その合計値を計算して返す `StringCalculator` クラスを実装する。

## 詳細仕様
1. メソッド `add(numbers: str) -> int` を持つ。
2. 入力が空文字 `""` の場合は `0` を返す。
3. 入力が `"1"` のように1つの数字の場合は、その数字を返す。
4. 入力が `"1,2"` のように2つの数字の場合は、その合計を返す。
5. 入力が `"1,2,3,4"` のように未知の数の数字でも、その合計を返す。

## 制約
- 言語はPythonを使用すること。
