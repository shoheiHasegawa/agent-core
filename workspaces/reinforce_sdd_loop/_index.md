# Workspace: Reinforce SDD Loop

ここは、SDD/TDDのループエンジニアリングを補強するための設計・議論を行うワークスペース（作業場）です。

## 📍 ルーティング指示 (Routing)
Agentは、本ワークスペースにアクセスした際、以下の順序で情報を取得・更新してください。

1. **現在の議論の焦点を知りたい場合**:
   👉 `tasks/context.md` を読んでください（常に最新の現在地が50行以内で要約されています）。
2. **タスクの全体進捗を知りたい場合**:
   👉 `tasks/progress.md` を読んでください。
3. **設計の決定事項や壁打ちの結果を残す場合**:
   👉 `docs/` 配下にMarkdownファイルを作成して議論のプロセスを保存してください（例: `docs/01_spec_format_design.md`）。

---
※このワークスペースでの壁打ち・設計が完了し、本番リポジトリ（`agent-core`のスキルやツール群）に反映させた後は、不要なファイルは `scratch/` と共に破棄し、クリーンアップされます。
