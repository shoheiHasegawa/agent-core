# 💡 Lessons Learned: cca-foundations

## 🤖 ルートA：Agent・仕組みの学び（CI / パイプライン / フレームワーク）

1. **Web公式ドキュメントの汎用ELTパイプライン確立**:
   - **生データ（Raw）不変の原則**: 47MBの巨大辞書やMCP全文は `docs/sources/` にそのまま永久保存し、いつでも再抽出・検証可能な状態を維持。
   - **決定論的クリーニング（Step 1）**: Web特有の装飾タグ（`<CardGroup>`, `<Tip>`等）や同一処理の冗長コード（TS/cURL）を正規表現で機械的に除去。本文の文脈や制約値は1文字も削らない。
   - **原文抜粋（Step 2）とカバレッジ監査**: AIによる要約（要約による情報落ち）を避け、シラバス（`docs/topic_index.md`）の25項目に沿って「原文をそのまま抜粋・配置」。`docs/coverage_report.md` で100%網羅を決定論的に検証。
   - ➔ **今後のあらゆる資格取得や新OSSの高速キャッチアップにおけるYou_Inc標準パターンとして資産化完了**。

2. **NotebookLMのコンテキスト純度とA/Bテスト設計**:
   - 47MB（約1,200万トークン）をそのまま食わせると、Lost in the Middleと推論平滑化（薄い要約）が発生する。
   - 10〜30KB（数千トークン）のドメイン別Packに小分けすることで、ポッドキャストの議論密度（Deep Dive度）が極大化する。
   - 「ソース分割のみ（統制群）」vs「出題論点特化プロンプト（介入群）」のA/Bテストを組むことで、プロンプト指示の効果を客観的に比較・検証可能にした（勉強会でのキラーデータ化）。

3. **Delivery型タスクにおけるSMART基準とIssue先行一覧起票**:
   - 資格取得などの成果物・期日固定型タスクは、全Sub-Issueを先に一覧起票することで全体ボリュームとバーンダウンを可視化。だらけと漂流を防ぐ。

## 🧠 ルートB：社長自身の気づき・内省候補（`second-brain` / 哲学・資産化の種）

1. **「社長のメガネ」哲学（教科書 vs コンテンツの境界線）**:
   - 誰でも手に入る「公式ドキュメントの要約や辞書的知識の羅列」には市場価値がない。
   - 一次情報（公式仕様）に対し、社長自身の葛藤・現場感覚・アナロジー（`second-brain` の Permanent Notes）という**「独自のメガネ」を通して解釈・再構成されたものだけが、他者が価値を感じるオリジナルな知的財産（コンテンツ・勉強会）になる**。

2. **二重運用の原則（試験対策の純度 vs 知的資産化）**:
   - **試験勉強中**: 公式用語との乖離（主観バイアス）を防ぐため、NotebookLMには公式Docs（純度100%）のみを投入。
   - **壁打ち・定着**: 思考の熱量が冷めないよう、壁打ちで腑落ちしたアハ体験はリアルタイムに `second-brain` のアトミックノートへ蓄積。
   - **合格後（資産化）**: 合格後に両者を合流させ、NotebookLM Studio（スライド/レポート）で勉強会パッケージを一発生成する。

3. **問題演習における引き算の英断**:
   - AIに問題を作らせると品質ブレや難易度チェックに認知リソースが溶ける（ヤクの毛刈り）。問題演習はプロが精査したUdemy英語模試に一本化し、NotebookLMは「インプット・耳想起・暗記」に純化する。
