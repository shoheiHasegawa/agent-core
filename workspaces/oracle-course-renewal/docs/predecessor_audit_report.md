- **現状のジレンマ**:
  - 1Z0-085（19c Bronze DBA）の試験対策をゴールに据えると、実機（26ai Free）では廃止・非推奨となった機能（EM Express、非CDB構成、OUI/DBCAのGUI操作、SYSMANユーザ等）を「実機では動きませんが試験に出ます」と教え続ける必要がある。
  - 逆に実機（26ai Free・CUI運用）を軸にすると、24下期ベースの練習問題（EM Expressでできること5選など）の大半が不適切となり、問題の抜本的な作り直しが必要になる。
- **意思決定事項**:
  - 本勉強会の最終ゴール（第6回のまとめテスト20問で測るべき到達点）を **「① 1Z0-085資格試験の模擬問題が解けること」** に置くか、**「② 実機ハンズオンを通じたOracleの基本アーキテクチャ理解＋基本操作の習得（資格頻出の普遍的知識に絞る）」** に置くか？

### 論点2：【座学 × 練習問題の整合性（SSOT化）】「スライドにない出題」の処置方針
- **現状のジレンマ**:
  - 全5回の練習問題（計38問）のうち、**半数以上が「スライドに一切書かれていない知識」を問うている**（さらに第3回問4・問5、第4回問1・問2等の致命的な問題文欠落・出題ミスが計6問存在する）。
- **意思決定事項**:
  - **アプローチA（スライド拡充型）**: 練習問題（良問）で問われている重要概念（COMMIT時のLGWR動作、UNDOの読み取り一貫性、セグメントとエクステントの関係、起動4段階の読込ファイル、DROP TABLEの影響範囲、プロファイル・クォータ、インスタンスリカバリ等）を**座学スライド側に逆算して追記し、スライドをSSOTとして完結させる**。
  - **アプローチB（問題剪定・再設計型）**: スライドで扱わない重箱の隅の問題（EM Expressの11択5選やORACLE_HOME複数リリース等）は練習問題から削除し、**各回の学習ゴールに直結する問題へ全面リファクタリングする**。
  - （※特に未作成の **第4回・第5回練習問題** と **第6回まとめテスト20問** を設計する際、AとBのどちらの基準で作るかの合意が必須）。

### 論点3：【実機ハンズオンの破綻箇所（技術的負債）】の修正範囲
- **現状のジレンマ**:
  - 前任者スライドのままハンズオンを進めると、以下の箇所で**確実にエラーまたは進行不能（手詰まり）が発生する**：
    1. **第1回**: `alter pluggable database freepdb1 save state;` の記述漏れ（次回EC2起動時にPDBがOPENされず全演習が停止）。
    2. **第4回**: SQL*Loader用の `/home/ec2-user/SQLLoader*` ファイルの生成手順不在、Data Pumpで空テーブル（`U1_.table1`）をエクスポートする論理ミス、`/opt/oracle/admin/FREE/dpdump` のパス相違、総合演習の `USER01` 再接続漏れ・表領域クォータ不足。
    3. **第5回**: フラッシュバッククエリで作成直後の表に `systimestamp - interval '3' minute` を指定して `ORA-01466` / 0件になる時間指定バグ、およびRMAN終了後の接続ユーザ（SYS実行時の `ORA-08185`）の不備。
    4. **第2回**: 「おまけ：ベクトル検索」が実際にはベクトル検索ではなくText-to-SQL（Ollama + `UTL_HTTP`）であり、かつ `utlsampl.sql` によるSCOTT消失など手順が混乱している。
- **意思決定事項**:
  - 未実施の **第4回・第5回ハンズオン手順** をどこまで修正・再構成するか？（特に第4回のSQL*Loader用CSV/CTLファイルをコマンド内ヒアドキュメント `cat << 'EOF'` で自己完結生成させるか、Data Pumpの対象テーブルをデータ入りの `table2` に変更するか、第5回のフラッシュバックを秒指定またはSCN指定／明示的待機に変更するか）。
  - 実施済みの **第1回・第2回スライド** をアーカイブ・復習用および来期（25下期）用としてどのレベルまでリファクタリングするか？（第2回の「おまけ：ベクトル検索」を残すか、削除・改題するか）。

### 論点4：【第6回（総復習スライド＋最終テスト20問）】の設計仕様
- **現状のジレンマ**:
