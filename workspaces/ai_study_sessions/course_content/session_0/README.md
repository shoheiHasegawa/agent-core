# Session 0: 「Agent駆動」の思想と、魔法の箱（Obsidian）の準備

## 🎯 本セッションのゴール
- 「毎回細かい指示を書かなくても、察して動いてくれる相棒（Agent駆動）」という理想の思想を共有する。
- 講座全体で使うローカルエディタ（Obsidian）のインストールと初期設定を完了する。
- 自身の環境（ChatGPT, Claude等）で、システムの根幹に指示を注入する方法（対応表）を理解する。

---

## 💥 【思想】プロンプトエンジニアリングからの脱却

あなたはAIを使うとき、毎回チャット欄に「あなたはプロのエンジニアです」「日本語で答えて」「このフォーマットで出力して」といった呪文（プロンプト）を入力していませんか？
これは非常に面倒であり、人間の認知負荷（疲労）を高めます。

本講座が目指すのは、**「Agent駆動（察して動くAI）」**です。
毎回指示を出さずとも、事前に「ルール」や「専門知識」を裏側（システム）にロードさせておくことで、AIがあなたの意図を汲んで自律的に動く環境を作り上げます。

---

## 🛠 【準備1】魔法の箱「Obsidian」のインストール

AIの最もネイティブな言語は「Markdown（マークダウン）」です。
本講座では、AIに読み込ませるルールやファイル群を管理するための「プレーンな箱」として、**Obsidian**というエディタを使用します。

1. [Obsidian公式サイト](https://obsidian.md/) からアプリをダウンロード・インストールしてください。
2. インストール後、本講座の教材データ（Vault）を開いてください。

> [!NOTE]
> Obsidian自体にAIを賢くする魔法の力があるわけではありません。単に「AIが読みやすいMarkdownを、ローカルで一番素直に管理できる透明なエディタ」であるため採用しています。

---

## 🗺 【準備2】BYO-AI環境別「システム設定」対応表

本講座では、受講者が日常的に使っているAI（BYO-AI: Bring Your Own AI）をそのまま使用します。
AIを「チャットボット」ではなく「システム」として振る舞わせるためには、チャット欄ではなく**「裏側のシステム設定欄」**にルール（Markdownファイルの内容）を注入する必要があります。

お使いのAI環境に合わせて、以下の【対応表】を確認してください。
今後のSession（第4回、第5回など）で「憲法」や「ルール」という言葉が出てきたら、ご自身の環境の以下の場所に**読み替えて**設定を行ってください。

| 使用するAI環境 | 「憲法・ルール」を設定する場所（機能名） | 備考 |
| :--- | :--- | :--- |
| **ChatGPT (Plus)** | `Custom Instructions` または `GPTs` の設定画面 | 汎用的なルールはCustom Instructionsへ。 |
| **Claude (Pro)** | `Projects` 機能の「System Prompt」またはナレッジ欄 | 憲法と役割を1箇所にまとめて書くことが多いです。 |
| **Antigravity (IDE等)** | リポジトリ直下の `GEMINI.md` や `AGENT.md` | ローカルファイルシステム上の絶対ルールとして機能します。 |
| **その他 (Cursor等)** | `.cursorrules` などのプロジェクトルート設定ファイル | |
