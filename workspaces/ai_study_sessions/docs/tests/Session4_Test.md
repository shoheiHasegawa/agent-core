# AI活用勉強会 テスト問題: Session 4

**テーマ:** 絶対的な制約としての「憲法（ルール）」
**問題数:** 全10問（理解チェック8問、応用シナリオ問題2問）

---

## 【基礎理解チェック：8問】

**Q1. 【単一選択（正しいもの）】**
Agent駆動における「憲法（グローバルルール）」の役割として、最も適切なものはどれですか？
- [x] AIに対して「What not to do（やってはいけないこと・制約）」を静的に注入し、自律的な行動の逸脱を防ぐこと。
- [ ] 特定のタスクの具体的な手順（How）を網羅的に記述し、AIに手取り足取り教えるためのマニュアルとして機能すること。
- [ ] ユーザーの好みに合わせてAIの口調やキャラクター設定（語尾など）を柔軟に変更すること。
- [ ] 過去のエラー履歴をすべて記録し、AIが同じミスを繰り返さないための学習用データとして活用すること。

**Q2. 【単一選択（誤っているもの）】**
AIにルールを守らせる方法として、**誤っているもの**を1つ選んでください。
- [x] 毎回のプロンプトの末尾に「必ず日本語で答えて」「この条件は絶対守って」と繰り返し手動で記述するのが最も確実で丁寧な使い方である。
- [ ] 常に適用されるべきグローバルな制約は、システム設定（Constitution）として自動的に注入される仕組みを作る。
- [ ] AIの行動選択肢を意図的に制限することで、AIがルールをどう解釈するか考える推論リソースを節約する。
- [ ] 制約（ルール）には単なる禁止事項だけでなく、「なぜそうするのか（Rationale）」という自己正当化の理由をインラインで明記する。

**Q3. 【複数選択（適切なもの）】**
「静的な構成定義の注入」がAIのパフォーマンスに与えるメリットとして、**適切なもの**をすべて選んでください。（複数選択）
- [x] AIが「どう振る舞うべきか（メタ・タスク）」を考える推論リソースを節約し、本質的な作業タスクに100%の知能を集中させることができる。
- [x] 人間が毎回同じ指示（プロンプト）を入力する手間と認知負荷をなくし、指示漏れによるエラーを防ぐことができる。
- [ ] 構成定義を注入することで、AIの言語モデル自体が再学習（ファインチューニング）され、永久に能力が向上し続ける。
- [ ] ルールを厳密に固定化することで、AIが自発的に新しいルールを創造し、人間の意図を超える提案をしてくれるようになる。

**Q4. 【単一選択（最も適切なもの）】**
ルールや規約を記述する際、「インライン・ラショナール（ルールの背景理由の併記）」が重要とされる理由はどれですか？
- [x] AIが文脈なしに禁止事項だけを提示されても応用が利かず、背景の「なぜ」を理解させることで未知の状況でも規約の意図に沿った行動がとれるから。
- [ ] 理由を長く書くことでコンテキストの消費量が増え、結果としてAIへの課金コストを意図的に抑えることができるから。
- [ ] 人間が後からルールを見直すための備忘録に過ぎず、実はAIの挙動にはほとんど影響を与えないから。
- [ ] ADR（アーキテクチャ・ディシジョン・レコード）へのリンクを貼るだけだとリンク切れのリスクがあるため、念のため併記するだけのものだから。

**Q5. 【単一選択（誤っているもの）】**
AIへの「制約」に関する考え方として、**誤っているもの（アンチパターン）**を1つ選んでください。
- [x] ルールは状況に応じてAI自身に柔軟に考えさせながら適応させた方が、推論能力の高さを活かすことができる。
- [ ] 決断の選択肢を事前に制限することは、AIと人間の双方の認知資源を保護する最適戦略である。
- [ ] 人間の行動選択肢は、システムとして注入される言葉（制約）によって物理的・強制的に規定されるべきである。
- [ ] AIへの制約は単なるプロンプトのお願いではなく、スクリプトと統合された「品質ゲート」としてシステム的に担保されるべきである。

**Q6. 【複数選択（誤っているもの）】**
ルールとプロンプトの関係について、**誤っているもの（アンチパターン）**をすべて選んでください。（複数選択）
- [x] 「絶対に」や「必ず」という強い言葉をプロンプトで多用すれば、憲法（システム設定）がなくてもAIはルールを完璧に守る。
- [x] 憲法（システム設定）には、プロジェクトの全作業手順（マニュアル）をすべて詰め込んでおけばAIが万能になる。
- [ ] 個別の作業指示（プロンプト）と、常に守るべき前提（憲法）は、設計上明確に分離して管理されるべきである。
- [ ] 憲法が肥大化しすぎると、AIのアテンションが分散し、かえって重要な制約を見落とすリスクが高まる。

**Q7. 【単一選択（正しいもの）】**
「人間の暗黙的なチェックリストをSOP（標準作業手順）として外部注入する」というプラクティスの目的は何ですか？
- [x] 評価や判断のタスクにおいて、人間の脳内にある属人的な基準を明文化して注入することで、AIの評価のブレ（主観性）を排除するため。
- [ ] 人間が普段から行っている手作業の手順をそのままAIに模倣させ、人間と全く同じ時間（速度）で作業を行わせるため。
- [ ] チェックリストを注入することで、AIがチェックの工程をスキップし、より迅速に結論を出力できるようにするため。
- [ ] 人間がミスをした際に「AIがチェックリスト通りにやらなかったからだ」と責任を転嫁するエビデンスを残すため。

**Q8. 【単一選択（最も適切なもの）】**
Agent駆動OSにおいて、「Leave No Trace（一時ファイルの自律破棄）」などのルールがグローバル憲法に定められている理由として、最も適切なものはどれですか？
- [x] 一時ファイルなどの「状態（ステート）」が残存すると、それが将来のタスクにおいて意図しないコンテキスト汚染を引き起こすアーキテクチャ上のリスクとなるため。
- [ ] ディスクのストレージ容量を節約するためだけの、インフラストラクチャ上の物理的な制限事項である。
- [ ] 一時ファイルが存在すると、ハッカーによる外部からのサイバー攻撃を受けやすくなるセキュリティ上の懸念があるため。
- [ ] どのようなファイルも、一度作成されると人間が手動で削除することがシステムの仕様上不可能に設計されているため。

## 【応用シナリオ問題：2問】

**Q9. 【単一選択（最も確実な対策）】**
**シナリオ:** あなたはAIにコードのレビューを依頼しています。毎回「セキュリティの観点で厳しく」「変数名はスネークケースで」とプロンプトで指示していますが、時々AIが指示を忘れて甘いレビューをしてしまいます。この問題を構造的に解決するための最適なアプローチはどれですか？
- [x] レビュー時の前提となる制約やコーディング規約を「憲法（設定ファイル）」として静的に定義し、レビューのたびにシステムから自動注入される仕組みを作る。
- [ ] プロンプトの最後に「前回も忘れましたが、今回は絶対に厳しくレビューしてください！約束ですよ！」と感情に訴えかける文章を追加する。
- [ ] 1回のチャットセッションをずっと継続し、AIがルールを忘れるたびに「ルール違反です」と繰り返し指導して完全に学習させる。
- [ ] AIのモデル（例：GPT-4）を別の会社のモデルに変更し、プロンプトの指示をより正確に聞いてくれるAIを探し続ける。

**Q10. 【複数選択（指摘すべき懸念点）】**
**シナリオ:** チームのリーダーが、「AIにルールを守らせるために、社内の就業規則から業務マニュアル、過去のクレーム対応事例まで、考えうるすべてのルールを1つの『大憲法ファイル』にまとめ、全AIエージェントに常時読み込ませるようにしよう」と提案しました。
Agent駆動の原則に基づき、この提案に対する懸念点として**適切なもの**をすべて選んでください。（複数選択）
- [x] 憲法が肥大化するとAIのアテンション（注意力）が崩壊し、かえって本当に守るべき重要な制約が見落とされるリスクが高まる。
- [x] すべての手順や事例（How）まで憲法に詰め込むことは、「普遍的な制約」と「特定タスクの手順」の混同であり、AIの推論リソースを無駄に浪費する。
- [ ] 情報量が多ければ多いほどAIは高度な判断ができるようになるため、この提案には全く懸念点がなく、むしろ理想的なアーキテクチャである。
- [ ] 大憲法ファイルを作成する際、人間がルールを箇条書きにするのではなく、AIが読みやすいように情緒的な長文で書き直す必要がある。
